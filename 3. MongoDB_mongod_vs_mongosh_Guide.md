# MongoDB: `mongod` vs `mongosh`

`mongod` and `mongosh` are two different programs in MongoDB.

-   **`mongod` = MongoDB Database Server**
-   **`mongosh` = MongoDB Shell (Command Line Client)**

  ------------------------------------------------------------------------
  Feature               `mongod`                `mongosh`
  --------------------- ----------------------- --------------------------
  Purpose               Runs the MongoDB        Connects to and manages a
                        database server         MongoDB server

  Role                  Database engine         Client application

  Stores data           ✅ Yes                  ❌ No

  Executes queries      Processes them          Sends them to `mongod`

  Must be running?      ✅ Yes                  ❌ No

  Default Port          27017                   Connects to port 27017
  ------------------------------------------------------------------------

------------------------------------------------------------------------

## 1. `mongod` (MongoDB Daemon)

`mongod` is the actual MongoDB server process.

Responsibilities:

-   Store documents
-   Read/write data
-   Create indexes
-   Authentication
-   Replication
-   Transactions
-   Handle client connections

### Start the server

``` bash
mongod
```

Or specify a data folder:

``` bash
mongod --dbpath "C:\data\db"
```

When it starts successfully:

``` text
Waiting for connections
Listening on port 27017
```

------------------------------------------------------------------------

## 2. `mongosh` (MongoDB Shell)

`mongosh` is the command-line interface used to communicate with a
MongoDB server.

It does **not** store data itself.

### Connect to a local server

``` bash
mongosh
```

or

``` bash
mongosh mongodb://localhost:27017
```

Example commands:

``` javascript
show dbs

use school

db.students.find()

db.students.insertOne({
    name: "John",
    age: 20
})
```

------------------------------------------------------------------------

## Common Error

If you see:

``` text
MongoNetworkError: connect ECONNREFUSED 127.0.0.1:27017
```

It means the MongoDB server (`mongod`) is not running.

Start it with:

``` bash
mongod
```

Or on Windows:

``` powershell
net start MongoDB
```

## Easy Analogy

-   **`mongod`** 👨‍🍳 = Kitchen (stores and prepares data)
-   **`mongosh`** 🧑‍💼 = Waiter (sends your requests to the kitchen)

Without the kitchen (`mongod`), the waiter (`mongosh`) cannot serve any
data.
