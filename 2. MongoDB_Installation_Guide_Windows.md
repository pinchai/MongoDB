# MongoDB Installation Guide for Windows 11

**Version:** MongoDB Community Server 8.3.4\
**Operating System:** Windows 10 / Windows 11 (64-bit)

## Objectives

-   Install MongoDB Community Server
-   Install MongoDB Compass
-   Install MongoDB Shell (mongosh)
-   Configure PATH
-   Verify installation
-   Create databases and collections
-   Perform CRUD operations

## Required Software

  Software                                  Description
  ----------------------------------------- --------------------------
  mongodb-windows-x86_64-8.3.4-signed.msi   MongoDB Community Server
  mongodb-compass-1.49.8-win32-x64.exe      MongoDB Compass GUI
  mongosh-2.8.3-win32-x64.zip               MongoDB Shell

## Step 1: Install MongoDB Server

Run:

``` text
mongodb-windows-x86_64-8.3.4-signed.msi
```

-   Choose **Complete**
-   Install MongoDB as a Service
-   Keep the default service account
-   Finish the installation

## Step 2: Install MongoDB Compass

Run:

``` text
mongodb-compass-1.49.8-win32-x64.exe
```

Connect using:

``` text
mongodb://localhost:27017
```

## Step 3: Install mongosh

Extract:

``` text
mongosh-2.8.3-win32-x64.zip
```

Example folder:

``` text
C:\Program Files\MongoDB\mongosh
```

## Step 4: Configure PATH

Add:

``` text
C:\Program Files\MongoDB\Server\8.3\bin
C:\Program Files\MongoDB\mongosh
```

Restart PowerShell.

## Step 5: Verify Installation

``` powershell
mongod --version
mongosh
```

## Basic Commands

``` javascript
use school
db.createCollection("students")

db.students.insertOne({
    name:"John",
    age:20,
    major:"Computer Science"
})

db.students.find()
db.students.find().pretty()

db.students.updateOne(
    {name:"John"},
    {$set:{age:21}}
)

db.students.deleteOne(
    {name:"John"}
)

show dbs
show collections
db
exit
```

## Windows Service

``` powershell
net start MongoDB
net stop MongoDB
sc query MongoDB
```

## Troubleshooting

### 'mongod' is not recognized

Add MongoDB Server **bin** folder to PATH.

### 'mongosh' is not recognized

Add the **mongosh** folder to PATH.

### ECONNREFUSED

``` powershell
net start MongoDB
```
